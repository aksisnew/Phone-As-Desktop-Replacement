# Phone as Desktop Replacement

So, from about past 1 year I have been trying to reduce my depndance on laptops and desktops and moving to phones.

> Some important things before moving forward
> 1. I have been doing this on my secondary phone without payment and authentication apps
> 2. I use keyboard mouse and a external monitor.
> 3. This is just a setup guide and does not show or have sponsorship from any brand
> 4. I cannot gurantee It will work on your device or not And is a experimental Project.

---

1. First the most important thing is , A big screen So you need atleast a phone compatible with screen mirroring and a TV with screen mirroring support. A keyboard and a mouse ( I use bluetooth wireless no dongle ones which dont need dongle to connect to phone)
2. The benefit is I can just carry the phone, keyboard mouse and mostly if suppose in hotel or so they have TV with them genrally compatible with screen mirroring wireless. This has reduced laptop load on me.
3. I have done web development ,python development on my phone, I am a web developer and a python developer so I can only confirm that these things work for other things like proper app compiling, maybe this setup wont work for you.
